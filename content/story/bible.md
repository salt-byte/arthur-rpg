### 梅林 · 导师；亚瑟一生的安排者

**一句话**：巫师。他安排了亚瑟的出生和登基，也早就看见了自己的结局和卡美洛的结局。

**行为逻辑**：让该当王的人当上王。他让尤瑟得到伊格赖因、把亚瑟藏起来、立石中剑，都服从这一条。

**要什么**：在自己被封印之前，把亚瑟送上王位、站稳；留下一个接班的人。

**命门**：对妮妙动了心，明知道结局，还是跟她走了（第 4 卷）。

**阻碍**：
- 内在：他知道自己在拦不住的那几个人里，所以不拦自己的结局
- 外在：摩根恨他；诸王不信一个巫师立起来的王

**弧线**：
- 开始时：什么都安排好了的人
- 中段转折：当上王的亚瑟开始不全听他的：剑鞘的话听了，王后的警告没听

**独立生活**：在不列颠各地奔走，替亚瑟拉拢支持的人、看预兆，回庄园的时间很少。所以他需要一个留在亚瑟身边的人。

### 亚瑟 · 国王；你一起长大的兄弟

**一句话**：埃克托家的养子，拔出石中剑成了国王。一生想做一个公正的王，最后和自己的儿子同归于尽。

**行为逻辑**：做一个公正的王：讲法、守誓，哪怕伤到自己最亲的人（第 20 卷他按法律判王后火刑）。

**要什么**：前期：证明自己配得上那把剑。中期：一张骑士平起平坐的圆桌。后期：保住王国和法。

**命门**：太相信规矩，也太相信身边的人：他不愿相信兰斯洛特和王后的事，又把国家交给了莫德雷德。

**阻碍**：
- 内在：年轻时不知情生下了莫德雷德，知道以后不知该怎么面对
- 外在：不服的诸王、摩根、莫德雷德

**弧线**：
- 开始时：在庄园里给凯当侍从、牵马擦盔甲，没有一点野心的少年
- 中段转折：圆桌建立，最好的年月
- 结束时：失去剑鞘、王后和最好的骑士，在卡姆兰和儿子同归于尽，被船接往阿瓦隆

**独立生活**：给凯擦盔甲、牵马、练剑；原文里拔剑前他就是凯的侍从。

**说话方式**：少年时直来直去；称王后话变少，常讲「法」和「誓」。绝不说：（拔剑前）我是王；（称王后，当众）我错了。

## 三、因果主线

每个转折按「新的压力 → 谁解读它 → 他选了什么方法 → 改变了谁的选项 → 可见的后果」写。

**故事前的状态**：尤瑟王死后十几年，不列颠没有王，诸侯各自为政。只有梅林知道尤瑟有个儿子，叫亚瑟，藏在埃克托爵士家。梅林早就看见：亚瑟会当上王、建起圆桌，最后死在自己儿子手里；他自己会在亚瑟最需要他之前被活埋。

**开场的变化**：梅林知道自己留不到最后，带回一个能在水面上看见将来的孩子，交给埃克托收养，和亚瑟、凯一起长大。梅林有了接班人；你有了一个家，也背上了一份你还不知道的义务。

**主角接下的任务**：第 1 章末，梅林告诉你亚瑟的身世，要你在他走后留在亚瑟身边替他看着。你自己要的更简单：这个家不散。

**升级与反转**：石中剑：你在石圈看见凯会冒认拔剑 → 你知道父亲会当众逼凯认错 → 你决定说不说（下半写选项）→ 凯和亚瑟之间留不留下疙瘩 → 亚瑟加冕，凯当上总管。

**升级与反转**：剑断：亚瑟和佩利诺决斗剑断、险些被杀 → 梅林判断亚瑟需要一把配得上王的剑 → 带他去湖边 → 亚瑟有了王者之剑和护身的剑鞘 → 也欠下了湖：剑终有一天要还回去。

**升级与反转**：婚事：梅林看见王后将来会爱上兰斯洛特 → 他警告亚瑟 → 亚瑟仍然娶了，因为圆桌和一百名骑士是她的嫁妆，也正是他想要的那张桌子 → 圆桌立起来，三个人之间的结已经系上。

**升级与反转**：梅林离开：梅林迷上妮妙，把法术教给她 → 他知道自己就在拦不住的那几个人里，不拦自己的结局 → 跟她去了康沃尔 → 被封在石下 → 宫廷里只剩你看得见将来，所有人都来问你，也开始有人怕你。

**升级与反转**：剑鞘：摩根恨梅林和尤瑟的血脉 → 梅林一走她就动手 → 偷走剑鞘扔进湖里 → 亚瑟从此会流血、会死 → 最后一战的致命伤由此而来。

**升级与反转**：圣杯：圣杯在宴会上显现 → 骑士们认为这是一生最大的荣誉 → 当众发誓出发 → 圆桌空了一半，很多人没回来 → 加拉哈德找到圣杯，是圆桌最光荣的时刻；兰斯洛特因为心里有王后没能找到。

**升级与反转**：揭发：阿格规文和莫德雷德盯住兰斯洛特和王后 → 他们认定这是削弱亚瑟的机会 → 带人当场揭发 → 亚瑟只能按法律判王后火刑 → 兰斯洛特劫法场，误杀加雷斯和加赫里斯 → 高文发誓复仇。

**升级与反转**：篡位：高文的誓言收不回 → 他逼亚瑟渡海去打兰斯洛特 → 亚瑟明知梅林说过摩高斯的孩子会毁掉他，还是把国家交给莫德雷德看管：他说拦不住，不如给他一次机会，这正打在他太相信身边人的命门上 → 莫德雷德伪造死讯篡位 → 亚瑟回师，高文战死前写信求兰斯洛特回来。

**高潮**：卡姆兰。和谈时一条蛇咬了一名骑士，他拔剑砍蛇，两军以为对方动手，混战开始。亚瑟刺死莫德雷德，自己受了致命伤；没有剑鞘，伤口止不住血。贝狄威尔把剑还给湖；摩根和几位女王用船把亚瑟接往阿瓦隆。

**结束时的状态**：圆桌散了，亚瑟去了阿瓦隆。王后进了修道院，兰斯洛特成了隐修士。你是最后一个看见过这一切的人。其他人怎样走到最后（谁和谁和解、谁死在路上、谁陪亚瑟到了最后），取决于你一路上说过的话，在下半写。

## 七、你在故事里做的决定
