# 文风卡

参考：《地海巫师》，勒古恩，蔡美玲译；《百年孤独》，马尔克斯，黄锦炎等译（样本 17 段，20354 字，见 `refs/index.md`）
学什么：《地海》学师徒和同伴的对白、法术的分量和代价、贴着学徒看；《百年》学一家人怎么被早就写好的结局追上：先报将来、平常口气讲反常的事、跳时间。《百年》对白只占 6%，家里的对白从《地海》厨房两段和 `content/story/voices.md` 来。

## 对白

- 师父答得比问的短，不解释。「“老师，我什么时候开始学艺呢？”“已经开始了。”」（dh03）只借短和不安慰；梅林怎么说照 voices.md（先说结果、带名字和期限）。
- 先做手上的事再开口。「法师没说什么，他经过格得身边，把油灯燃亮，再把书放回架上。」（dh04）
- 家里吵架，一方把话落到孩子或家务上收住。「“不要成天想入非非，最好关心关心孩子吧，”」（bn02）
- 最要紧的话说不出口，临走留一句土方子。「“拿热石头贴着脓疮，”说着，她一转身就走出了房间。」（bn03）
- 大道理说到一半，被一样小东西打断。「雅柔，你那只小龙偷了一块饼干。」（dh08）

## 场面

- 看见将来的那一幕：先报将来（谁、在哪、手里拿着什么），再切回眼前的家务。「多年以后，奥雷连诺上校站在行刑队面前，准会想起父亲带他去参观冰块的那个遥远的下午。」（bn01）
- 看见了也照样放行，只给一个脸色。「大法师一听到船名，脸色就沉了下来，但他说：“就搭那艘船去吧。”」（dh05）
- 祸事穿过家里一个寻常的位置，家里人正干着活。「乌苏娜正在那儿准备打碎三十六只鸡蛋来做面包」（bn05）
- 停在一个背影或一个不动的人上。「没有挥手，也没有高喊」（dh09）

## 看人看事

- 贴着学徒看，写他嘴硬、不服，不替他辩解。「格得没接腔。回答法师总是不容易。」（dh03）
- 预见不保险：有时应验了才明白，有时看错。「有时，预感十分明确，却没应验。」（bn04）
- 知道结局的人照常干活，给结局做准备。死神「请阿玛兰塔替她穿针引线」（bn07）
- 法术有代价，记在身体上：救完村子的孩子「不吃不睡不言不语」（dh01）

## 不学的

- 两本书的情节、人名、地名：格得、欧吉安、费蕖、柔克、马孔多、布恩蒂亚家。
- 《百年》的长句连环（一句串十几个地点）和魔幻夸张（血拐弯、尸体焖一天）；性和乱伦的段落。
- 欧吉安的格言（「要聆听，必先静默」），用户 2026-11-09 否过这种师父腔。 <!-- style-ok -->
- 译文的翻译腔和台湾用语：「当……时」「藉」「罗」「蛮」「一方面……另一方面」、「象」当「像」。 <!-- style-ok -->

## 仿写示范

**对白**
```
埃克托把凯的剑横在灶台上，刃口崩了个豁，有指甲盖大。
埃克托: 谁砍的？砍的什么？
凯: 磨坊的门闩。冻死了，我弟弟推不开。
亚瑟: 是我叫哥砍的。
埃克托: 磨石拿来。谁砍的谁磨，就在这儿磨给我看。
凯把磨石推到亚瑟手边，推到一半又捞回去，往石面上啐了口唾沫抹匀。
凯: 萝卜手，一边待着。你那两只手冻得跟萝卜一样，磨出来是把锯。
```

**动作**
```
凯射偏了，箭落在磨坊塘的冰面上。亚瑟踩上去捡，冰咔地裂开，他下去半截。
凯趴在岸边把弓递过去，差一臂够不着。
你解下腰绳，一头拴在凯的脚踝上，顺着冰面爬出去，揪住亚瑟的领子。
凯往后蹬，靴跟在岸上犁出两道泥。
亚瑟被拖上来，手里还攥着那支箭。
凯: 一支箭比你值钱？蠢猪。
亚瑟把箭递给他。箭羽湿透了，贴成一条。
```

**情绪**
```
动身去伦敦的前一晚，埃克托在火塘边给亚瑟的旧靴子上油，叫你拿浅木碗打水来擦泥。
你把碗搁上炉砖。水面一晃，平了。
水里是下雪的教堂院子。亚瑟握着一把剑，剑柄上没缠凯的皮绳。埃克托跪在他跟前，帽子掉在雪里。
你的太阳穴一跳一跳地疼。
-> 大人，到了伦敦，您别给人下跪。
    埃克托: 跪谁？我这膝盖只跪主教。水端过来。
-> （把碗端过去）
埃克托蘸湿布，一下一下擦亚瑟的靴尖。
```
