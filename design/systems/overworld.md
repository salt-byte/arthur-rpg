# 大地图与探索设计页

系统 id：overworld · 层：mvp · 负责 skill：world-map · 参数文件：`content/data/overworld.json`、`content/data/spawns.json`
照：《Vampire's Fall 2》的大地图（敌人看得见、自己走动，你决定什么时候交手；没有随机遇敌；逃跑回上一个圣龛；圣龛祈祷回满血；圣龛之间快速传送；打死的敌人不回来；野外能捡到宝物） · 规则核对来源：Steam 商店页、Pocket Gamer 评测、用户玩过原作（「杀死了就没了」，2026-11-06）；追人的距离和概率查不到，照插件 `world-map` 的 graveholme 实例，标「未核实」 · 参考代码：`overworld-grid`
上游：`design/CONCEPT.md` 三层循环 5–15 分钟那一层、「在地图上走、找人说话」「看水面」；定调题「明雷」「按章节线性开放」「世界状态变化：只做关键几处」；2026-11-06 玩法参考改成照《Vampire's Fall 2》

> 这页分两层。上半页给人看，下半页给实现看。

## 一句话
一章开一片地方，你在里面走动、找人说话、在发光的水面上看将来；敌人在地图上看得见、自己走动，靠近了会追你，打哪只、绕开哪只由你挑，打死的就没了；血不够了回圣龛祈祷。

## 一个例子
第 1 章，你跟凯和亚瑟进了北边的林子。

1. 小路右边的蕨丛旁有两只狼在来回转，左边路中间横着一只死羊，树后蹲着个弓手。屏幕上方写着「下一步：去林子深处找头狼」。
2. 你朝那两只狼走过去，还隔四五格，灰狼抬起头朝你跑来。碰上了，开打。两回合打完，学徒拿到经验，地上几枚银币。凯少了 3 点血，没回。
3. 路边有一座齐腰高的石龛，龛里的圣母像脸都磨平了。你在跟前按确认祈祷：三个人的血都满了，这座石龛记成「上次祈祷的地方」。
4. 你绕开了死羊那边的弓手，往林子深处走。头狼带着两只狼守在空地中间，一动不动：这是任务要打的，绕不过去。
5. 打完，狼从地图上没了，不会再来。路边那个弓手还蹲在树后，回头去打他还是直接去石圈，随你。
6. 第 1 章结束后，庄园、林子、石圈都关了，第 2 章换成伦敦。

## 1. 玩家感受
地方不大，走几步就有人可以说话，不让人在空地图上找路。

敌人看得见，开打前就知道要打什么，可以先换好上场的人（用户定：明雷）。它们会走动、靠近了会追：想打的自己找上门，不想打的绕开（2026-11-06 用户改：照《Vampire's Fall 2》）。

打死的敌人就没了，一片地方打干净了就安静下来，不会刷怪（用户玩过原作确认）。每只敌人只能打一次，打不打是真的选择：打了多一份经验和掉落，也多挨几口。

血带出战斗，不够了就回圣龛祈祷。圣龛之间可以直接传过去，回去补血不用走回头路（照原作）。

一章一片地方，跟着故事往前走，走过的地方不再回去（用户定：按章节线性开放）。

世界只在几处关键的地方看得出你的选择（用户定：只做关键几处）：玩家路过时会认出「这是因为我那时候……」。

落在三层循环的 5–15 分钟那一层：在一张地图上挑着打、升级、换装备、回圣龛。

## 2. 规则
### 每章的地方
| 章 | 主线去的地方 | 支线去的地方 |
|---|---|---|
| 1 | 埃克托爵士的庄园（院子、马厩、阁楼）、森林、石圈 | — |
| 2 | 伦敦（教堂墓地、比武场、教堂、住处）、贝德格兰森林 | — |
| 3 | 亚瑟的营帐、林中泉边、湖、卡美洛 | 往北的路、城堡、绿色礼拜堂 |
| 4 | 卡美洛（大厅、厨房、阁楼）、湖 | 去红地的路 |
| 5 | 卡美洛（大厅、宴会厅、王后的房间外、礼拜堂）、城外法场、城下河边 | 比武场、阿斯托拉特 |
| 6 | 欢乐堡外的营地、海边、多佛海岸、卡姆兰（营地、战场）、湖边 | — |

第 6 章伦敦塔那一段（莫德雷德对王后说话）你不在场，用过场演，不进地图。

### 走动和说话
- 俯视的格子地图，上下左右四个方向走。电脑用方向键或 WASD；手机用屏幕左下的方向键，右下一个确认键、一个菜单键。
- 面对人或东西按确认：和人说话、看水面、开门、看物件、祈祷、开宝物。

### 敌人
| 规则 | 出处 |
|---|---|
| 敌人在地图上看得见，平时在自己那一块地方里转 | 看得见、自己走动照原作；只在自己那一块转照 graveholme，未核实 |
| 你离它 4 格以内，它每走一步有六成多的可能朝你追来；不出它那一块地方，隔着墙的不追 | 未核实，照 graveholme |
| 你走一步，它走一步 | 未核实，照 graveholme |
| 和它上下左右挨着就开打；没有随机遇敌 | 没有随机遇敌照原作；怎么算碰上原作未核实 |
| 走近时敌人头上显示名字和几只（「狼 ×2」） | 自创 |
| 任务要打的敌人（首领、挡在必经之路上的）站着不动，绕不过去 | 首领不动照 graveholme，未核实；挡路是我们的 |
| 打赢了这群敌人从地图上没了，祈祷、换地方、读档都不会让它回来；没有能刷的敌人 | 照原作（用户玩过确认，2026-11-06）。Steam 讨论区有人说在洞里刷怪，个别地方可能会刷新，待确认；本作不做 |
| 能上场的同伴超过 2 个时，碰上以后先弹出出战选择 | 我们的 |
| 一章里能绕开的敌人 4–6 群，每群 1–3 只，放在支路、空地、宝物旁边 | 自创：时长预算，见公式 |
| 能绕开的那块地方离必经的路至少隔两格：追得到路边，上不了路 | 自创（第 10 步白盒）：只打必须打的路线要走得通，「绕开」才是真的选择 |

### 圣龛
| 规则 | 出处 |
|---|---|
| 每片地方至少一座圣龛：路边的石龛、泉边的石十字、教堂里的小祭坛 | 外形是我们的 |
| 面对圣龛按确认祈祷：三个人的血回满，这座记成「上次祈祷的地方」，同时自动存档 | 回满血照原作；存档是我们的 |
| 在圣龛跟前可以传送到这一章祈祷过的另一座圣龛；传过去以后，那一座记成上次祈祷的地方 | 传送照原作（圣龛之间快速传送）；传过去算不算「上次祈祷」原作未核实，我们定：算 |
| 战斗里逃跑，或者输了选「回圣龛」：回到上次祈祷的圣龛跟前，三个人回满血；那群敌人留在原地、血回满 | 逃回上一个圣龛照原作；回满血、敌人回满是我们定的 |
| 每章开始时，这章第一座圣龛自动记成「上次祈祷的地方」 | 我们的：还没祈祷过就逃跑时也有地方回 |
| 刚回到圣龛的 3 步里，敌人不追你 | 照 graveholme，未核实 |
| 祈祷不会让打死的敌人回来 | 照原作（用户确认） |
| 每场任务战前，走路 30 秒内有一座圣龛 | 自创：血带出战斗以后，任务战前要能回满 |
| 在圣龛跟前可以重新分配技能点（成长页） | 自创 |

### 宝物
- 野外宝物每章主线 2 处、有仗的支线各 1 处，每处挨着一群小仗，城里和剧情地方不放（2026-11-10 第 10 步定，和装备页「一章约 4 件」的投放对上）：树洞里塞着的包袱、翻倒的货车、墙角的箱子。面对它按确认打开，掉落见装备页。开过的不再有东西。照原作（野外能捡到宝物）。
- 宝物旁边常常守着一群能绕开的敌人：想拿就得打。

### 水面
- 能看将来的水面（石圈的积水、湖、泉）只在剧情走到这里时发光。
- 不发光时按确认，只显示“水面很平静。”

### 看得出你的选择的四个地方
| 地方 | 第几章 | 看你的什么选择 | 你会看见什么 |
|---|---|---|---|
| 湖边 | 第 4 章，去追摩根时 | 第 3 章末谁都没说（D3c） | 梅林的灰兜帽挂在芦苇上，可以拿起来；告诉过梅林或亚瑟的路线，芦苇上什么也没有 |
| 圆桌大厅 | 第 5 章法场之后 | 第 4 章的选择、「美手」支线、凯走没走 | 死去的人的椅子盖着布，离开的人的椅子空着；阿格规文、加雷斯、凯的椅子按你的选择不同 |
| 卡美洛城下的河边 | 第 5 章 | 伊莲恩支线 | 谁都不说（或没做）：一条小船漂到城下，船上躺着穿白衣的少女；其他路线：河边只有洗衣服的人 |
| 卡姆兰营地 | 第 6 章开战前夜 | 凯、加雷斯的下场 | 篝火边站着还在的人；凯走了的路线，他常坐的那块石头空着 |

这四处之外，地图不随选择变化；人说的话会变（对话页）。

### 换章
章末弹出章节过渡，告诉你这章没做的支线；上一章的地方和圣龛全部关闭，不能回去。

# 给实现看

## 3. 公式
| 名字 | 公式 | 为什么是这个数 |
|---|---|---|
| 一片地方的大小 | 约 30 × 20 格 | 一屏多一点，走到边不超过十几秒 |
| 走路速度 | 每秒 4 格 | 先按感觉定，白盒后调 |
| 每章地方数 | 3–5 片 | 一章里走路不超过三分之一 |
| 关键地点之间 | 走路不超过 30 秒 | 不让人在空地图上找路 |
| 追人 | 4 格以内，每步 65% | 未核实，照 graveholme（插件 `world-map`）；按绕墙的走路步数量 |
| 每章能绕开的敌人 | 4–6 群，每群 1–3 只 | 一群小仗 1–2 分钟，全打一章多 5–10 分钟；全程从约 2 小时 50 分钟变成约 3 小时 20 分钟到 3 小时 50 分钟，超出 GAME_BRIEF 估的 2.5–3 小时，第 11 步范围复盘定砍不砍 |
| 两次碰到敌人之间 | 走路 1–3 分钟 | CONCEPT「两次动脑的时刻之间」：旧设计最长隔 10 分钟，白盒踩中 |
| 任务战前的圣龛 | 走路 30 秒内 | 血带出战斗，任务战按满血来调 |

## 4. 边界情况
- **敌人站在窄路上**：任务要打的才放在唯一的路上；能绕开的会走动，堵在窄路上时等它走开，或者打。
- **回到圣龛后又碰上**：圣龛跟前一格不放敌人；回来的 3 步里敌人不追。
- **两群敌人同时挨着你**：先挨上的那群开打；另一群原地停 3 步，打完不会马上又开打。
- **敌人追着你走进剧情触发的格子**：先演剧情，演的时候地图上所有敌人停住。
- **同时发生**：走进新地方时正好触发剧情对话，先演剧情，演完再显示「下一步」。
- **存档中途**：进新的一章、每完成一个任务步骤、每次祈祷自动存档；存打败记录、开过的宝物、上次祈祷的圣龛。读档时你回到存档那一刻站的位置，还活着的敌人回到各自的出生点。
- **四个地方的变体**：进入这片地方时按剧情变量选一种样子，在这片地方里不再变。
- **玩家反着来**：全绕开，只打任务要打的，也能通关（战斗页「怎么设计每一场」第 4 条按这个等级调任务战）；全打光，一片地方安静下来，没有刷的地方。不跟着标记走、到处乱逛也行。

**退化打法和对策**：
- *拉着敌人去圣龛，祈祷完马上打*：等于满血打一仗，这就是原作的节奏，留着。
- *逃跑回满再来*：敌人也回满，你还得走回来，不占便宜，留着。
- *读档刷宝物*：开宝物的结果由存档里的种子定，读档再开一样（装备页）。

## 5. 依赖
- 用到：任务（标记、谁出现在哪、任务敌人放在哪、什么时候开新地方）；看水面与预言簿（哪些水面在发光）；同伴（营地篝火边站着谁）；战斗（碰上开打、逃跑和输了回哪）；装备（宝物掉什么）；成长（圣龛跟前重新加点）。
- 被谁用：战斗（碰到敌人开打）；对话（走到人跟前说话）；存档（位置、打败记录、开过的宝物、上次祈祷的圣龛）。

## 7. 验收条件（进 TASKS.md）
功能：
- [ ] `--playtest` 进入每片地方时打印名字和这片地方里的人、敌人（每群：名字、几只、会不会走动）、圣龛、宝物、发光的水面。
- [ ] 走到能绕开的敌人 4 格以内，打印「狼 ×2 开始追」；跑出它那一块地方，打印「不追了」。任务敌人始终打印「不动」。
- [ ] 碰上打印「开打：林子边的狼」和出战名单；赢了打印「林子边的狼 已移除」；再走到那里、祈祷之后、读档之后都不再出现。
- [ ] 祈祷打印「祈祷：三人回满，记下：林边石龛，已存档」；传送打印「传到：庄园小礼拜堂」。
- [ ] 逃跑或输了选回圣龛，打印「回到：林边石龛」；那群敌人血满、还在原来那块地方。
- [ ] 第 1 章「只打任务要打的」路线和「全打」路线都能走完，各打印打了几群、学徒几级。
- [ ] 四个地方各按两种路线打印选中的样子（例：D3c → 湖边「灰兜帽」；D3a → 湖边「无」）。
- [ ] 第 2 章开始后打印第 1 章的地方和圣龛全部关闭。

体验（白盒和停靠点 C 按这几句问）：
- [ ] 第 1 章森林里，玩家没人提示就去撞下一只看得见的敌人（CONCEPT 最大风险的观察句）。
- [ ] 打完一场小仗，玩家看一眼血，再决定回石龛还是接着打。

截图：
- [ ] 发光和不发光的水面分得清；祈祷过和没祈祷过的圣龛分得清；开过和没开的宝物分得清；四个地方的不同样子各一张；手机宽度下方向键、确认键、菜单键都在拇指够得到的地方。
