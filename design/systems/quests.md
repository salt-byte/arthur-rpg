# 任务设计页

系统 id：quests · 层：mvp · 负责 skill：quest-design · 参数文件：`content/data/quests.json`
上游：`design/CONCEPT.md` 的「找人说话」；剧情谱 outline.json 的主线节点和四条支线；定调题「混合指引」

> 这页分两层。上半页给人看，下半页给实现看。

## 一句话
每章一条主线任务，一步步带你走完这章的剧情，地图上标着下一步去哪；几条支线各围着一位骑士的将来，要听别人说了才知道去哪找，章末就关了。

## 一个例子
第 1 章的主线叫「庄园的冬天」。

1. 一开始，屏幕上方写着「下一步：跟凯去林子里赶狼」，地图上林子入口有一个标记。
2. 打完狼群，下一步变成「回庄园的路上经过石圈」，标记移到石圈。
3. 第 3 章的支线「高文与绿衣骑士」不一样：圣诞宴会上绿衣骑士走后，高文对你说：「一年以后我得去北边找一座绿色礼拜堂，我连它在哪都不知道。」任务记录里抄下他这句话，地图上没有标记；你得自己去找知道路的人。
4. 支线没做完就往前走到梅林要出远门那一幕，会先弹一句「往前走，『高文与绿衣骑士』就做不了了」。

## 1. 玩家感受
主线不让人迷路：任何时候都知道下一步去哪（用户定：主线标点）。

支线像真的在打听消息：谁告诉你的、原话怎么说，都记在任务记录里，要自己顺着去找（用户定：支线口述）。

支线会过期，但不会悄悄过期：关门之前一定提醒一次。

## 2. 规则
### 主线
一章一条，每一步就是剧情谱里的一个节点。

| 章 | 主线 | 步骤（剧情谱节点） | 其中的仗 |
|---|---|---|---|
| 1 | 庄园的冬天 | 赶狼（1101）→ 石圈（1102）→ 阁楼见梅林（1103）→ 出发前一晚（1104） | 狼群；梅林的影子 |
| 2 | 石中剑 | 墓地（1201）→ 比武（1202）→ 教堂（1203）→ 加冕与叛乱（1204）→ 庆功宴（1205） | 贝德格兰之战 |
| 3 | 湖中剑与圆桌 | 营帐（1301）→ 泉边决斗（1302）→ 湖（1303）→ 婚礼与圆桌（1304）→ 梅林要出远门（1305） | 和佩利诺 |
| 4 | 梅林离开 | 梅林不见了（1401）→ 剑鞘（1402）→ 十几年后（1403）→ 莫德雷德（1404）→ 圆桌宴席（1405） | 追摩根 |
| 5 | 圣杯与裂痕 | 圣杯（1501）→ 留守（1502）→ 揭发（1503）→ 法场（1504）→ 高文的誓言（1505） | 守城 |
| 6 | 最后一战 | 欢乐堡（1601）→ 渡海（1602）→ 假死讯（1603）→ 多佛（1604）→ 卡姆兰（1605）→ 湖边（1606） | 欢乐堡；多佛登陆；卡姆兰 |

### 支线
| 支线 | 什么时候开 | 谁告诉你、怎么说 | 什么时候关 | 其中的仗 |
|---|---|---|---|---|
| 高文与绿衣骑士 | 第 3 章婚礼之后的圣诞宴会 | 高文说他得去北边找绿色礼拜堂 | 梅林要出远门（1305）之前 | 去礼拜堂路上的野人 |
| 厨房里的「美手」 | 第 4 章十几年后 | 凯抱怨厨房来了个不肯说名字的帮工；一年后，凯说「那小子跟着一个姑娘出了北门，说是去红地」 | 圆桌宴席（1405）之前 | 红骑士 |
| 毒苹果 | 第 5 章留守 | 王后的侍女说王后要为高文他们设宴 | 揭发（1503）之前 | 没有 |
| 阿斯托拉特的伊莲恩 | 第 5 章留守，兰斯洛特回来以后 | 贝狄威尔说比武场上有个戴红袖子的骑士，没人认得 | 揭发（1503）之前 | 比武 |

每条支线最后都是一次看水面和一个关键选择（看水面与预言簿页）。

### 指引
| | 主线 | 支线 |
|---|---|---|
| 地图标记 | 有，标在下一步的地点 | 没有 |
| 屏幕上方 | 「下一步：……」一行 | 不显示 |
| 任务记录 | 当前这一步 | 谁告诉你的、他的原话、已经做到哪 |
| 新地方 | 走到哪开到哪 | 有人告诉你以后，那个地方才出现在地图上 |

### 关门
- 每章的关键选择那一步之前，开着的支线会关。
- 关之前弹一次提醒：「往前走，『……』就做不了了。现在往前走吗？」可以选「先不走」回去做。
- 关了的支线按「谁都不说」结算（绿衣骑士按两个选项都不算），章节过渡时告诉玩家这章没做的事。

### 任务决定谁在哪
任务走到哪一步，决定地图上出现哪些人、哪些敌人。比如「美手」支线开了，厨房里才有那个不说名字的帮工。

# 给实现看

## 3. 公式
| 名字 | 公式 | 为什么是这个数 |
|---|---|---|
| 主线步数 | 每章 4–6 步，等于剧情谱这章的节点数 | 一步一个节点，剧情谱改了任务跟着改 |
| 仗的数量 | 主线每章 1–3 场，每条支线 0–1 场 | 一场 2–3 分钟，一章 20–30 分钟里打仗不超过三分之一 |
| 支线关门点 | 本章关键选择那一步的前一步结束时 | 支线的结果要赶在主线决定之前定下来（V1、V2 要在高文发誓时可用） |

## 4. 边界情况
- **0**：不做任何支线也能通关。结局「湖边」总能选；「康沃尔的巨石」只看主线第 3 章；「卡美洛」要凯还在身边（不做支线时加雷斯会死在法场），所以有的路线没有它。
- **同时发生**：第 5 章两条支线同时开着，各走各的，同一次提醒里一起列出。
- **还没被告诉就走到支线地点**：支线的地点在被告诉之前不出现在地图上；卡美洛城里的支线人物（厨房帮工）在支线开之前不出现。
- **提醒时选了「先不走」**：回到原地，不再弹，直到下次走到同一个关门点。
- **存档中途**：每完成一步自动存档（单一存档位）；战斗中不存。
- **玩家反着来**：先跑完所有支线再走主线，可以；主线某一步之后才开的支线，之前不出现。

## 5. 依赖
- 用到：剧情谱（节点、支线、开关点）；对话（「和谁说话」的步骤、口头指路）；看水面与预言簿（每条支线最后的决定）；战斗（「打赢某场」）。
- 被谁用：大地图（标记、谁出现在哪、敌人放在哪）；界面（任务记录、屏幕上方的下一步）；存档。

## 6. 可调参数（登记进 content/data/quests.json）
| 参数 | 当前值 | 范围 | 调它会改变什么 |
|---|---|---|---|
| quests[] | 每条：id、主线 / 支线、章、开的节点、关的节点、步骤（类型：去哪 / 和谁说话 / 打赢哪场 / 看水面 / 关键选择） | — | 任务内容；第 10 步填全 |
| main_marker | true | — | 主线标点 |
| side_marker | false | — | 支线口述（用户定） |
| warn_before_close | true | — | 支线关门前提醒 |
| autosave_on_step | true | — | 每步自动存档 |

## 7. 验收条件（进 TASKS.md）
- [ ] `--playtest` 每一步打印任务状态变化：「主线 1：赶狼 → 石圈」。
- [ ] 主线每一步打印标记坐标，支线任何时候都不打印标记。
- [ ] 不做支线的路线：1305、1405、1503 之前各打印一次关门提醒；之后打印「S1 关闭：两个都不算」「S2 关闭：按 S2c」等。
- [ ] 走完整条主线的脚本在三条路线（全说、全不说、混合）上都能从第 1 章走到结局。
- [ ] 截图：任务记录里支线那一条显示告诉你的人的原话。
