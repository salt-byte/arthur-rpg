# 圆桌座位设计页

系统 id：fellowship · 层：mvp · 负责 skill：quest-design（状态变化写在剧情数据里）、ui-layout（面板） · 参数文件：`content/data/fellowship.json`
上游：`design/CONCEPT.md` 的世界回应「身边的人变了」；招牌画面

## 1. 玩家感受
关系用离散状态，不用好感度数值（用户定，2026-11-05）。

每个重要人物在面板上有一个座位，玩家一眼就能看出谁在身边、谁走了。座位只因为关键选择而变，不会因为送礼、多聊几句慢慢涨。所以每一次变化玩家都知道是哪个决定造成的。

座位一变，面板自动弹出一下：标出是谁、变成了什么，配上那个人当时说的一句话。

## 2. 规则
### 状态
| 状态 | 面板显示 | 能否出战 | 怎么进入 |
|---|---|---|---|
| 未加入 | 不显示座位 | 否 | 初始状态 |
| 在桌 | 座位亮 | 能 | 剧情加入事件 |
| 离开 | 座位暗，名字还在 | 否 | 「说或不说」的后果，或支线结果 |
| 离世 | 座位上放一件遗物图标 | 否 | 剧情决定（传说里的死亡，或玩家选择导致的） |

### 状态转换
| 从 → 到 | 条件 |
|---|---|
| 未加入 → 在桌 | 剧情加入事件 |
| 在桌 → 离开 | 某个选项的后果写了这一条 |
| 离开 → 在桌 | 只能通过剧情指定的「回归」事件，每人最多一次 |
| 任意 → 离世 | 剧情事件；不可逆 |

所有转换都写在剧情数据里，不由公式算出来。

### 面板
- 第 1–2 章还没有卡美洛，面板叫「身边的人」；卡美洛建成（第 3 章）后同一个面板改叫「圆桌」，座位排成一圈。
- 规则不变，只换外观和名字。

### 出战
- 每场战斗前，从「在桌」的人里选最多 2 位上场。
- 剧情战可以指定必须上场的人。
- 指定的人已经离开或离世时，这场战斗必须有一个替代版本：换人，或者学徒单独作战。剧情数据里两种都要写，检查脚本查缺。

### 台词
同一个人在不同状态下说不同的话：
- **在桌**：正常对话。
- **离开**：在地图上还能遇到，台词换成离开后的版本。
- **离世**：别人会提到他。

## 3. 公式
本系统不用数值公式。数量上的约定：

| 名字 | 值 | 为什么 |
|---|---|---|
| 有座位的人物 | 6–8 位（具体名单由 story-bible 定） | 面板一圈放得下，玩家记得住；每人都要有至少一个碎片或支线，人多了写不完 |
| 每人「回归」次数上限 | 1 | 离开要有分量；能反复回来就等于没离开 |
| 一章内座位变化 | 至少 1 次（主线碎片保证） | 让「身边的人变了」每章都被看见 |

## 4. 边界情况
- **在桌的人是 0 个**：学徒单独作战。战斗内容要允许这种情况，单人版本可以降低难度。
- **一个选项同时改变几个人**：全部执行；面板按顺序逐个弹，每个停留 2 秒，点击可跳过。
- **离世的人在预言簿里还有没做的决定**：那个碎片按到期处理，结算成「不说」，并在结局回顾里写明。
- **回归事件触发时，那个人已经离世**：回归事件不出现。
- **存档中途**：所有人的状态和已用回归次数都在存档里。
- **玩家反着来**：故意让所有人都离开。允许，后面的战斗更难，结局回顾如实念出。

## 5. 依赖
- **用到**：
  - 预言碎片（prophecy）：选项后果。
  - 任务（quests）：支线结果。
  - 故事圣经：人物名单、加入和离世事件。
- **被谁用**：
  - 战斗（combat）：谁能上场。
  - 对话（dialogue）：按状态选台词。
  - 结局回顾。
  - 界面（ui）：面板。
  - 存档（save）。

## 6. 可调参数（登记进 content/data/fellowship.json）
| 参数 | 当前值 | 范围 | 调它会改变什么 |
|---|---|---|---|
| states[] | 未加入 / 在桌 / 离开 / 离世 | — | 状态集合；加状态要回来改这页 |
| rejoin_max_per_person | 1 | 0–2 | 离开的分量 |
| panel_rename_chapter | 3 | — | 「身边的人」改叫「圆桌」的章节，跟着故事里卡美洛建成走 |
| change_popup_seconds | 2 | 1–4 | 座位变化提示停留多久 |
| roster_max | 8 | 6–12 | 面板最多放几个座位 |

## 7. 验收条件（进 TASKS.md）
- [ ] `--playtest` 每次状态变化打印：人物、旧状态 → 新状态、触发它的选项或事件 id。
- [ ] 白盒第 1 章：选「说」和选「不说」两条路线，凯的最终状态不同，并且都打印出来。
- [ ] 离开的人不出现在出战选择列表里；剧情战缺人时，走替代版本（打印走了哪个版本）。
- [ ] 读档后所有人的状态和回归次数与存档前一致。
- [ ] 截图：面板上在桌 / 离开 / 离世三种座位看得出区别，不靠颜色也能分辨（有图标或文字）。
