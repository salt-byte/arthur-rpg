# 预言碎片设计页

系统 id：prophecy · 层：mvp（结局回顾属于 playable） · 负责 skill：quest-design、dialogue-authoring · 参数文件：`content/data/prophecy.json`
上游：`design/CONCEPT.md` 的「预视」（战斗外部分）和「说或不说」两个动作；招牌画面；硬否决第 7 条

## 1. 玩家感受
在石圈、圣泉这类「看见未来」的地点，或某个剧情事件里，玩家会看到某个人将来的一幕。形式是一张静止的画面，配两三句具体的描写。

到了决定点，玩家面对两到三个选项：说给当事人、说给另一个人、不说。这是游戏里最重的选择：带一个「不可撤回」标记，选完立刻自动存档。

之后两章内，一定有人提起它。

## 2. 规则
### 碎片的一生
| 阶段 | 发生什么 |
|---|---|
| 看见 | 在地点或事件里触发；记进「预言簿」（玩家随时能翻，看已看见的画面和还没做的决定） |
| 等待 | 碎片停在预言簿里，直到它的决定点 |
| 决定点 | 剧情里的一个场景（可以紧接着看见，也可以是之后再见到那个人时，比如圆桌大厅）；弹出说或不说的选项 |
| 结算 | 按选项执行后果：圆桌座位变化、剧情变量、谁知道了这件事；立刻自动存档 |
| 回读 | 之后两章内，至少一句台词提到这次选择 |
| 到期 | 画面里的事在某章发生；决定点没被走到（支线没做完）就到期了，按「不说」结算 |

### 数量
- 主线每章 1 个碎片，决定点在主线必经的场景里，一共 6 个。
- 每条支线 1 个碎片，决定点在支线结尾，一共 2–4 个。
- 全程 8–10 次决定。

### 选项
| 选项 | 何时有 | 后果由谁定 |
|---|---|---|
| 说给当事人 | 当事人在桌，或在决定点的场景里 | 每个碎片在剧情数据里写明 |
| 说给另一个人 | 每个碎片指定 1 个候选人（比如告诉亚瑟，而不是当事人） | 同上 |
| 不说 | 永远有 | 同上；「不说」也必须有后果和回读，不能是没事发生 |

### 记录谁知道了什么
每个碎片对应故事圣经里的一条事实（fact）。说给某人，就把那人加进这条事实的「知道的人」名单。对话的条件、知识边界检查、结局回顾都读这份名单。

### 存档
只有一个存档位，靠自动存档，不提供手动多存档位。所以玩家没法存档后试一遍再读档反悔（「说出口的话不能收回」）。存档细节见 save 系统。

### 结局回顾（playable 层）
最后一战之后，按碎片顺序逐条念出：

1. 你看见了什么。
2. 你告诉了谁，或者没说。
3. 那个人后来怎样了。

## 3. 公式
| 名字 | 公式 | 为什么是这个数 |
|---|---|---|
| 主线碎片数 | 每章 1 个 × 6 章 | 每章一个最重的决定，玩家记得住；多了就稀释分量 |
| 选项数 | 2–3 | 两个太像是非题，四个以上玩家算不过来后果 |
| 回读窗口 | 决定后 2 章内 | 再远玩家就忘了自己选过什么，回读没感觉；来自 CONCEPT 硬否决第 7 条的设计约束 |
| 画面文字 | 每个碎片 2–3 句，每句不超过 30 字 | 手机一屏内看完，不需要翻页 |

## 4. 边界情况
- **当事人在决定点前离开或离世**：「说给当事人」灰掉，并显示原因（「凯已经离开了」）；剩下的选项照常。
- **候选人也不在**：只剩「不说」；这时把决定点改成一句旁白结算，不弹一个只有一个选项的菜单。
- **同一件事已经被别人告诉过当事人**：剧情数据里要为这种情况写一个变体选项（「提起这件事」）；检查脚本发现缺了就报警。
- **一个选项同时改变几个人的座位**：全部执行；圆桌面板按顺序逐个提示。
- **存档中途**：进入决定点场景前先存一次；选项弹出时关掉网页，再打开会回到选项面前，不会跳过。
- **玩家反着来**：
  - 全部不说：允许，故事按传说原样走，结局回顾逐条念出「你没有说」。
  - 每次都说：允许，同样有代价。

## 5. 依赖
- **用到**：
  - 对话（dialogue）：决定点场景和回读台词。
  - 故事圣经：事实和「知道的人」名单。
  - 地图（exploration）：「看见未来」的地点。
- **被谁用**：
  - 圆桌座位（fellowship）：选项的后果会改座位。
  - 任务（quests）：支线结尾是决定点。
  - 结局回顾。
  - 存档（save）。

## 6. 可调参数（登记进 content/data/prophecy.json）
| 参数 | 当前值 | 范围 | 调它会改变什么 |
|---|---|---|---|
| main_visions_per_chapter | 1 | 1–2 | 决定的密度 |
| options_min / options_max | 2 / 3 | 2–4 | 每次决定的复杂度 |
| recall_window_chapters | 2 | 1–3 | 回读多快出现 |
| autosave_on_decision | true | — | 能否反悔；关掉等于违背承诺，不应改 |
| save_before_decision_scene | true | — | 中途退出的安全性 |
| expire_as | 不说 | — | 支线没做完时碎片怎么结算 |
| vision_text_max_sentences / vision_sentence_max_chars | 3 / 30 | — | 画面文字长度 |

## 7. 验收条件（进 TASKS.md）
- [ ] `--playtest` 在白盒第 1 章打印：看见碎片 → 进入预言簿 → 决定点 → 选项 → 后果（座位变化 + 变量 + 「知道的人」名单变化）→ 自动存档。
- [ ] 检查脚本：每个碎片的每个选项，包括「不说」，在之后 2 章内都至少有一句回读台词；缺了报错。
- [ ] 决定后读档，选项面板不再出现，结果保持不变。
- [ ] 当事人离开后进入决定点：「说给当事人」显示为灰色并带原因。
- [ ] 截图：选项上的「不可撤回」标记可见；预言簿能翻到已看见的画面和待做的决定。
